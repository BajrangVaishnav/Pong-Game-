# Contributing to Pong Game

Thank you for your interest in contributing!

## How to Contribute

1. Fork this repository.
2. Clone your fork.
3. Create a new feature branch.
4. Make your changes.
5. Test your changes in a browser.
6. Commit and push your changes.
7. Open a Pull Request.

## Development Guidelines

- Write clean and readable JavaScript.
- Keep the project lightweight.
- Test keyboard and mouse controls.
- Test mobile responsiveness when changing controls or layout.
- Explain your changes in your pull request.

## Reporting Bugs

Please open a GitHub Issue and include:
- Bug description
- Steps to reproduce
- Expected behavior
- Browser and device information

Thank you for helping improve Pong Game!
