# 🎮 Pong Game

A classic Pong game built using HTML, CSS, and Vanilla JavaScript.

Play against an AI-controlled opponent, improve your reflexes, and enjoy a simple arcade gaming experience.

## ✨ Features

- 🎮 Classic Pong gameplay
- 🤖 AI-controlled computer opponent
- 🖱️ Mouse paddle controls
- ⌨️ Keyboard controls
- ⚡ Real-time ball movement
- 🎯 Collision detection
- 🏆 Live scoreboard
- 🔄 Game reset functionality
- 🌐 Browser-based gameplay

## 🎮 Controls

| Key | Action |
|---|---|
| Mouse Movement | Move Player Paddle |
| Arrow Up | Move Paddle Up |
| Arrow Down | Move Paddle Down |
| SPACE | Start / Pause Game |
| R | Reset Game |

## 💻 Run Locally

1. Clone this repository:

```bash
git clone https://github.com/BajrangVaishnav/Pong-Game-.git
```

2. Open the project folder:

```bash
cd pong-game
```

3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.
